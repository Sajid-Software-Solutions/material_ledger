## How to read the status

- **Partial** identifies named automated subcases or a retained contract, and states the remainder of the original Given/When/Then. It does not certify the whole scenario.
- **Source implemented** is static review only; execution/manual evidence is still required.
- **Manual not run** identifies an acceptance scenario without representative-device/user evidence.
- **Gated** is an approved deferred capability, not a silently omitted completed requirement.
- **Integration pending** delegates executed gate results to [IMPLEMENTATION_EVIDENCE.md](IMPLEMENTATION_EVIDENCE.md). No Flutter, Git or database command was executed for this document.

The draft implementation review had verified 11 draft unit tests and five Chrome browser adapter tests. Additional immutable-base, durable retry schedule, reference advisory and UI regressions were added afterwards. The current source includes eight reference-advisory tests and 44 expanded UI cases; those counts describe available cases, not an executed gate claim. Their final passing counts, complete-suite results, database execution and build identities belong in IMPLEMENTATION_EVIDENCE; test existence below is not a pass claim.

## Guarded decisions and remaining release boundaries

These are the supplied decisions/requirements, not new product requirements:

- **D01 — retention/shared devices/export:** preserve the current user-isolated device-local state. No automatic purge, retention duration promise or new plaintext export has been approved. Quarantined raw data, retired envelopes and pending journals can accumulate; their clearing/retention policy remains a product/security decision. Owner isolation is not disk encryption, and browser storage deletion/private-mode loss is not cloud recovery.
- **D02 — parties:** existing plain party inputs and permitted directory projections are used. No new party master, account creation or extra personal disambiguator is claimed.
- **D03 / PRJ-DRF-014 — cloud/collaboration/multiple drafts:** deferred. A single prior operation pointer recovers unresolved follow-up; it is not a general active-draft catalogue or cross-device sync. No new analytics workflow-run identity is added.
- **D04 / PRJ-IMP-001..006 — import/paste:** general project Excel/CSV import and building TSV mapping/preview remain unavailable. Uploading a workbook is only an attachment. Source mappings, limits, provenance, security/financial exclusions and rollback require approval before an import surface exists.
- **D05 — persisted building retirement:** current candidate blocks omission of active physical scope IDs through the trusted update for all permitted actors. The operational/commercial dependency-cleared retirement workflow is not implemented; history, Common and Accounts allocations are not deleted/reinterpreted.
- **D06 — atomic ownership/journal:** Web Locks plus synchronous localStorage provide the actual browser owner fence. The active draft's epoch, owner, revision and retired bit are one JSON envelope. Journal and recovery-pointer records are separate keys; a Web Lock does not make their multiple localStorage writes crash/quota atomic. Retirement writes the active tombstone before its historical copy; the browser failure test proves that specific ordering only. Native SharedPreferences locks are in-process, not cross-process; new critical setup commands are blocked there. Unsupported/nonsecure browsers fail closed, with no broadcast-only fallback.
- **D07 — dates:** optional dates retain null; explicit Today is separate from restoring or clearing a date. No newly invented default is required by this candidate.
- **D08 / Section17 — platform/performance/user trials:** only actual tested support may be advertised. Chrome adapter execution does not certify Windows Edge, macOS Safari, iPad/iPhone Safari, Android Chrome, Firefox or native platforms. The complete layout/text/scaling/reader/touch/keyboard matrix, configured load targets, p95 timings and office/site trial are not established by widget tests.
- **D09 — analytics:** categorical schema extensions are allowed; exact run correlation and broader identities/replay are not. Live PostHog ingestion, phase latency/upload measurements and aggregate dashboard denominators remain separate evidence. Analytics failure must not prevent UI navigation, local persistence or commands.
- **D10 — current field limits:** actual schema/configuration remains authoritative. Full field length/date/code limit inventory and real readback are required before release; no truncation or destructive normalization is accepted as a substitute.

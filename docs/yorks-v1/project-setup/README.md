# Project setup implementation

The product owner authorized implementation of the reviewed project setup core on 3 October 2026. This folder retains the supplied version 1.0 Markdown specification, interaction addendum, registers and synthetic contracts. Existing Yorks authority and protected backend rules continue to apply.

The new create/edit experience is gated by `YORKS_V1_PROJECT_SETUP`, default `false`. The current accepted screen remains the route fallback while acceptance is incomplete. Enable the flag explicitly in a local/test review lane. It does not authorize deployment or production writes.

General project imports, building-paste mappings, cloud/collaborative drafts and exact analytics run correlation remain deferred/gated. The 5 October owner request authorizes multiple independently saved device-local project setups: Create Project starts empty and Resume selects the saved draft. This bounded approval supersedes the earlier multiple-local-draft deferral; it does not authorize cloud sync or collaboration. Existing building retirement is conservatively blocked until its operational/Accounts reconciliation policy is defined. No scope history is deleted.
